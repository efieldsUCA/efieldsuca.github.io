Wonkybot

WonkyBot — My UCA senior design capstone: an autonomous differential-drive robot that clears an arena of colored pneumatic balls and sorts them into respective colored buckets. A Raspberry Pi 5 runs the ROS 2 Jazzy stack; a Raspberry Pi Pico handles the drive motors, servos, and stepper arm. A single Intel RealSense D455 does double duty, feeding depth-based obstacle avoidance for Nav2/AMCL navigation and driving an HSV-plus-shape vision classifier that distinguishes balls from buckets. Includes a vision-only fallback controller for when SLAM localization isn't available, and a phone-mic voice interface to start and select runs.

Randomizing Passcode

This is an embedded systems project that I thought of recently. It will consist of 3 circuits that would work in tandem to secure and open a lock. One circuit uses an 8-bit shift register IC, which would have specific values/operators depending on the Q# pin. Code for it would be randomized, and only the user will know the values/operators. The second circuit is a piezo buzzer that is used as a sound indicator, and the third circuit uses led's for visual. All three circuits are routed to a rasperry pi pico for PWM and coding.
